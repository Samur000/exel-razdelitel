# Разделитель Excel

Сайт, который делит Excel-файл на отдельные файлы по значениям выбранной колонки.
Всё работает в браузере: файл никуда не отправляется, сервер не нужен.

**Пример:** `студенты.xlsx`, колонка «Курс» со значениями 1–4 → `Курс_1_студенты.xlsx`, `Курс_2_студенты.xlsx`, …

## Как пользоваться

1. Перетащить файл в окно или нажать «Выбрать файл».
2. Если листов несколько — выбрать лист.
3. Нажать на колонку, по которой делить.
4. Посмотреть результат («Просмотр»), скачать всё одним ZIP или отмеченные файлы по одному.

## Что умеет

- Форматы: `.xlsx`, `.xlsm`, `.xltx`, `.xls`, `.xlsb`, `.ods`, `.csv` (UTF-8 и Windows-1251).
- Шапку находит сам (строку-заголовок над таблицей тоже переносит). Повтор шапки посреди таблицы пропускает.
- Оформление `.xlsx` сохраняется: цвета, шрифты, границы, ширина колонок, высота строк, объединённые ячейки в шапке, закреплённые строки, автофильтр, условное форматирование.
- «2» и «2 », «Москва» и «москва» считаются одной группой.
- Строки с пустым значением идут в отдельный файл `…_пусто_…`.
- Запрещённые в именах файлов символы заменяются на `_`.

## Ограничения

- Формулы заменяются готовыми значениями (иначе после переноса строк они ссылались бы не туда).
- Из `.xls`, `.ods`, `.csv` переносятся данные, форматы чисел, ширина колонок и объединения; цвета и шрифты — нет.
- Макросы из `.xlsm` не переносятся, результат всегда `.xlsx`.
- Картинки, диаграммы и выпадающие списки в ячейках в новые файлы не попадают.

## Публикация на GitHub Pages

1. Создать репозиторий на GitHub и загрузить в него содержимое этой папки.
2. В репозитории: **Settings → Pages → Source: Deploy from a branch**, ветка `main`, папка `/ (root)`.
3. Через минуту сайт будет по адресу `https://<логин>.github.io/<репозиторий>/`.

Можно и без GitHub: открыть `index.html` двойным щелчком — всё работает локально.

## Устройство

- `index.html`, `css/style.css` — страница.
- `js/splitter.js` — логика: чтение, поиск шапки, группировка, сборка файлов.
- `js/app.js` — интерфейс.
- `vendor/` — библиотеки ExcelJS 4.4.0, SheetJS 0.20.3, JSZip 3.10.1 (лицензии рядом).
